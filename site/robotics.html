Evaluation method

Compare policies under the same physical conditions.

Prism projects each test condition, verifies it with vision, and stores the result. Operators can repeat the same test and track which conditions cause success or failure.

  1. 01
    Project the condition.

    Show the required object pose, work area, and task state in the workcell.

  2. 02
    Verify the scene.

    Use vision to confirm the physical state before each run starts.

  3. 03
    Compare and track.

    Run both policies against the same verified cases and record which conditions cause success or failure.

How Prism works

Control each test.
Measure each policy.

Prism shows the operator how to set the scene. Vision checks the physical state. Prism starts the evaluation only when the state is correct.

01 / Stage

Set the test condition.

Project the required object position and task setup into the workcell.

02 / Verify

Check the physical state.

Check object identity, pose, occlusion, and tolerance before the robot moves.

03 / Learn

Compare the result.

Link each success or failure to the physical state that caused it.
