02 / SOFTWARE REACHES THE SURFACE

See the physical loop

The test starts
before the robot moves.

Test code can specify a position. It cannot make an operator put the cup there. Prism closes that gap with projected guidance and camera verification, connected to the lab’s code through our SDK.

  1. 01

    Define the case.

    Upload placements through the SDK, or generate a set for the task.

  2. 02

    Project. Place. Verify.

    The instructions appear on the table. Cameras check the actual physical setup.

  3. 03

    Run the robot.

    Clear the guidance before the evaluation. Compare models against the same starting conditions.

  4. 04

    Connect the result.

    Link the outcome from the lab’s evaluator or Prism’s scoring workflow to the task, model version, and verified setup.
