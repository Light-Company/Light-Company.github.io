# Prism evaluation workflow

An organic content campaign for The Light Company / Prism Robotics, prepared November 1, 2026.

## The campaign
Prism connects physical scene setup, policy evaluation and results. The campaign explains that workflow through real lab footage, product pages, practical guides and a scene-history walkthrough.
Primary action: discuss a workcell at https://lightcompany.ai/contact. Secondary action: register station interest at https://lightcompany.ai/order. Neither action purchases a product.

## Delivered
- A substantial Prism Robotics page and a dedicated workflow explanation.
- An interactive scene-history walkthrough using example data, excluded from indexing.
- Four educational guides, a resource hub and a downloadable evaluation checklist.
- Company, careers, contact, trust, terms, privacy, cookies and accessibility pages.
- Shared site navigation/footer, canonical metadata, Article/WebPage/Organization/Breadcrumb structured data, a canonical sitemap and AI-readable summaries.
- An eight-week editorial/distribution plan, keyword map, source notes and ready-to-edit social copy in this kit.

## Voice
Direct and specific. Name the task, explain what Prism does, and show what the user gets. Use normal headings and short paragraphs. Keep implementation details in technical documentation.

Approved names: The Light Company; Prism Robotics; Prism IRL. “Git for your physical space” describes saving, comparing and recreating test scenes. It does not imply a Git integration or perfect physical rollback.

## Boundaries
No verified model-ranking data was supplied. The Arena-style workspace stays illustrative and noindex. Do not promote its numbers as results. Product copy reflects owner-confirmed features and a review of the existing evaluation software. No verified open requisitions, standard prices, delivery guarantees or security certifications were supplied.

The legal pages cover the website. They do not establish an unknown legal entity, jurisdiction, enterprise data agreement or product warranty. Those details need owner/legal review before a commercial contract relies on them.

No paid advertising, outreach, social posting, Search Console submission or external analytics enrollment was performed. Distribution copy is prepared, not sent. The site's technical SEO is implemented; organic performance remains unmeasured.

## Assets
social-preview.png reuses the already approved blue brand preview; it is not newly generated artwork. New pages use real existing lab footage and founder photography. The manifest describes the actual preview asset only.

## Maintenance
Content source: lib/company-content.mjs, lib/company-guides.mjs, lib/company-legal.mjs. Run npm run company:build to regenerate routes, HTML, sitemap and reading files. Update evidence labels in visible copy and machine-readable text together. Replace illustrative scores only when the measured trials, protocol and evidence can be published together.
